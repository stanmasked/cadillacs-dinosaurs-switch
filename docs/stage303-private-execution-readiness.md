# Stage303 — compiled MAME 0.106 dino catalog vs private ROM

## Objective and actual findings

The private workspace now contains the user's canonical, authorized
`dino.zip` (16 ROMs) and the code-only Windows PE32 MAME 0.106
artifact from successful Stage297 GitHub Actions. Original game content
and any derived images are never uploaded to the public GitHub repository.

We performed a second *independent* content check: compared the original
ROM bytes with `dino-driver.xml`, the ROM inventory generated by
the *compiled historical Windows MAME executable* with its ROM-free
`-listxml` command. This does **not** re-run MAME with original game data.

Real local findings:

- `dino-driver.xml` has one runnable game `dino`, compiled from
  `cps1.c`, with **exactly 16 ROM declarations**.
- The privately normalized `dino.zip` contains **exactly 16 names**.
- Each XML entry matches the public source's name, size, CRC32, SHA1,
  memory region and offset.
- Actual original ROM bytes independently match **all 16/16** compiled
  XML size, CRC32 and SHA-1 values.
- ROM region declarations: CPU1 3, GFX1 8, CPU2 1, SOUND1 4.
- The compiled MAME executable has an Intel **i386 PE32** header.

The bundle's XML is historical executable-generated metadata, not a
cryptographically signed statement; XML/ROM agreement is **not equivalent**
to the MAME runtime loading, executing or displaying the original game.

## Reproducible private catalog gate

`tools/mame0106_private_driver_xml_gate_303.py` reads a bounded
compiled MAME XML artifact and private original `dino.zip` and
fails closed on an altered ROM, wrong name/size/hash/region/offset, an
unexpected clone driver, duplicate compiled entry, unsafe path, or
oversized/malformed XML.

Run privately on the machine where original files are stored:

~~~bat
python tools\mame0106_private_driver_xml_gate_303.py ^
  --driver-xml C:\private\mame290-bundle\dino-driver.xml ^
  --rom C:\private\roms\dino.zip ^
  --out C:\private\audits\stage303-compiled-xml.json
~~~

A successful private report contains only the status
`PRIVATE_DINO_COMPILED_DRIVER_XML_AND_ROM_MATCH_UNAUTHENTICATED`,
aggregate region-entry counts, and boolean markers; **no ROM bytes,
personal file paths, ROM or file SHA digests, images or input bytes**.

## Execution capability diagnostic

`tools/mame0106_private_host_readiness_303.py` performs a
read-only PE32/x86 header check and differentiates:

- `NATIVE_WINDOWS_MAME_EXECUTOR_CANDIDATE_UNTESTED`
- `WINE_MAME_EXECUTOR_CANDIDATE_UNTESTED`
- `BLOCKED_NO_HISTORICAL_MAME_WINDOWS_EXECUTOR`

The Wine candidate status **does not prove that 32-bit Wine works** or
that the MAME process executed; the tool never runs any game process.

Usage:

~~~bat
python tools\mame0106_private_host_readiness_303.py ^
  --mame C:\private\mame290-bundle\mame0106.exe ^
  --out C:\private\audits\stage303-host.json
~~~

On Linux where Wine is available, supply `--wine /usr/bin/wine` to
verify the basic existence/executability of a Wine launcher, *not* its
behavior. Do not misrepresent it as a passed real-ROM experiment.

In the current container, Wine and 32-bit runtime support are unavailable;
native compilation of this historical MAME bundle for Linux is not
straightforward because the supplied backend is Windows-specific.
Therefore we have **not performed a real `-verifyroms dino` process**
or original-game boot in this environment.

Once a compatible trusted Windows/Wine environment is available, the
existing Stage300 `tools/mame0106_private_dino_boot_probe_300.py`
is the next exact gated command, followed later by Stage298's private
activity-selected input replay.

python -m unittest discover -s tests -p 'test_mame0106_private_*_303.py' -v
~~~

The tests use only **invented tiny** ROM payloads and synthetic XML/PE
headers. No copyrighted original ROM or captures are used by public CI.

## Evidence limits

Even a Stage303 success demonstrates only **compiled ROM catalog
agreement with private original ROMs**. It does not prove authentic
WolfMAME binary provenance, original INP/WLF replay, video/audio
causal correctness or physical Nintendo Switch parity. The original
game's INP/WLF input recordings are not accessible in the current
container. Do not publish original ROM, INP, WLF, MNG or screenshots.
